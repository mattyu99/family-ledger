# 💖 甜心記帳本 (Sweetheart Family Ledger) v1.0.6

一套基於 **React Native + Expo SDK 57** 與 **Supabase PostgreSQL Realtime** 打造的跨平台家庭共同記帳系統。  
支援 **Android 原生 App（APK）、電腦網頁版（Web）與手機瀏覽器（PWA）** 多端併行，具備**多人協同記帳、即時雙向同步、離線隨身記帳、生活手帳記事、固定與分期帳單追蹤、Google 帳號一鍵綁定與身分電子鎖、4 位數安全防護、6 大全要素資料備份**與**雲端 OTA 熱更新**功能。

---

## 🌟 核心特色與架構

1. **多端併行運作（手機 APK + 電腦網頁 Web）**：
   - **外出隨手記**：手機安裝 Android APK 原生 App，外出買菜、加油、用餐秒開秒記。
   - **月末大螢幕對帳**：電腦瀏覽器開啟網頁版，大螢幕檢視收支統計與一鍵匯出 Excel。
   - **資料 100% 即時互通**：所有終端皆連線至同一組 Supabase 雲端資料庫，手機記帳電腦即刻跳出。
2. **全新 4 大功能頁籤架構（職責分明好找）**：
   - **📝 明細**：近期收支清單、即時搜尋、智慧店家膠囊快篩、待辦提醒與悠遊卡餘額小工具。
   - **📊 統計**：四大財務 KPI、收支類別排行榜、動態彩色進度條與成員支出貢獻分佈。
   - **💳 帳單支付**：專屬管理中樞，集中「週期扣款與固定帳單 (含分期攤提)」、「信用卡與悠遊卡支付帳戶 (含對帳)」、「常用付款方式」以及「記帳分類」。
   - **⚙️ 家庭設定**：純粹專注於家庭成員名冊（身分認領/管理）、邀請家人與安全 PIN 碼、整本帳本全要素備份與系統版本日誌。
3. **一人一機身分架構 ＋ 一鍵雙向撥零用錢（方案 D）**：
   - 每位家庭成員各自使用自己的手機進入帳本，首頁清晰標記 `📱 我 (本機)`。
   - 記帳時預設自動帶入本人身分，亦可自由切換「付款人」指定由誰代表支付。
   - **🎁 撥發零用錢雙向機制**：自動為出資家長記「支出」，並為受款小孩記「零用錢收入」，小孩帳戶具備正向結餘且維持家庭收支平衡。
4. **📝 家庭生活記事、待辦總覽與辦妥連動記帳（手帳模式 ＋ 辦妥回報 ＋ 連動支出）**：
   - 在記帳彈窗一鍵切換 `[ 📝 記事 ]`，記錄生活雜記、靈感、採買備忘或家庭待辦。
   - 自動以 $0 建立，**100% 嚴格排除於財務收支統計**，財務報表永遠乾淨精準。
   - 支援「⏰ 待辦提醒日期」設定，首頁頂部具備「🔔 今日生活待辦提醒」溫馨膠囊與倒數排程預告。
   - **辦妥確認彈窗 (方案 B)**：未完成待辦點擊打勾時喚起專屬確認視窗，指定辦妥成員、填寫「辦妥補充說明/回報」、快捷標籤，並可自由選擇「連動記一筆支出」或「僅標記完成」。
   - **連動記帳智慧退回草稿防護 (Option 2B)**：連動記帳途中若取消，自動退回辦妥確認彈窗，回報備註與人員狀態 100% 完好保留。
   - **綠色回報留言氣泡 ＋ 連動膠囊**：已辦妥卡片以專屬綠色留言氣泡呈現辦妥說明（如「已於全聯買齊、發票放客廳鞋櫃」），並展示連動支出膠囊，一鍵點擊查看對應記帳明細。
   - **正文超連結與括號標籤支援**：自動偵測內文網址轉為藍字超連結跳轉外部瀏覽器；相容半形 [ ]、全形［ ］與粗括號【 】標籤提取主題。
5. **🗓️ 週期扣款、固定帳單與信用卡分期付款追蹤**：
   - **水電瓦斯固定帳單**：契合台灣各縣市台電、自來水、瓦斯之單雙月繳排程與待繳核對清單（方案 B），到期一鍵確認入帳。
   - **📦 信用卡分期付款追蹤**：支援 3~36 期與自訂期數，每期自動標記 `(第 X/Y 期)`，具備已繳視覺進度條，繳滿全額自動祝賀與除役。
6. **💳 ✕ 🚌 雙分頁整合卡片智慧對帳看板 ＋ 悠遊卡查帳整合 (方案 A+B) ＋ 通用動態加值**：
   - 整合對帳看板，頂部支援 `[ 💳 信用卡 ]`（依卡片結帳日）與 `[ 🚌 悠遊卡 ]`（自然月）雙模式即時無縫切換。
   - **悠遊卡查帳整合 (方案 A+B)**：支援儲存 10~16 碼完整卡號；首頁小卡餘額右側善用天然留白提供微型末四碼複製標籤；對帳頁面提供完整卡號展示、一鍵複製與悠遊卡官網即時跳轉捷徑，零擁擠且查帳極致便利。
   - **通用動態出資加值**：悠遊卡加值出資來源全面動態化（現金、信用卡、銀行轉帳、悠遊付、街口等），支援記錄日常透過悠遊付 App 靠卡加值與指定銀行帳戶出資之金流。
   - **內部轉帳終點可視化**：轉帳與加值紀錄專屬呈現「📥 轉入目標卡片 (終點)」或「📥 轉入受款成員 (終點)」，底層依結構化帳戶 ID 綁定，備註與店家欄位 100% 自由填寫。
   - **自然月對帳嚴格排他校正**：重構儲值卡對帳演算法，徹底杜絕跨卡通配與重複列入，加值存入統計精確無誤。
7. **🛡️ 資料自主備份與「6 大全要素封存指標網格」**：
   - 2x3 雙排指標網格，即時呈現「📝 交易明細」、「👨‍👩‍👧 家庭成員」、「🏷️ 自訂分類」、「💳 支付卡片」、「🗓️ 週期/分期」、「📱 付款方式」共 6 大類完整筆數。
   - 備份檔案 100% 完整封存所有自訂客製化紀錄，支援「🔄 安全合併」與「⚠️ 完全覆蓋」兩種模式，跨裝置還原零失真。
8. **完善的管理員權限與安全體系**：
   - **🔒 家庭門禁安全鎖（新成員加入通道管控）**：家庭設定新增門禁安全開關，上鎖時全面阻斷持邀請碼之新訪客加入並隱藏家庭名冊，有效防範邀請碼外流風險。
   - **4 位數安全 PIN 碼**：預設為 `8888`，管理員可自由修改。新裝置認領管理員身分時須驗證此碼，防止他人冒充奪權。
   - **最後一位管理員防呆保護**：系統強制每本公帳至少保留一位管理員，禁止自己降級自己，亦無法將最後一位管理員降級。
   - **PIN 碼緊急救援恢復**：若在其他裝置遺失管理員權限，一般成員可憑 4 位數 PIN 碼一鍵即時升級/恢復為管理員。
   - **角色預覽模式（Preview Mode）**：管理員可一鍵切換至一般成員視角進行權限測試，頂部常駐提示橫幅且可一鍵安全退出。
9. **靈活的邀請碼與門牌機制**：
   - 帳本底層綁定全球唯一永久 ID（`ledger_id`），邀請碼為尋路門牌。
   - 支援「自訂邀請碼（如 `SWEETHOME`）」與「重新產生隨機邀請碼（舊碼自動作廢）」。
   - **資料庫級唯一性防撞**：全系統同一時間一組代碼只對應唯一帳本，絕不打架混淆。
   - 支援複製專屬邀請連結（含網址參數），LINE 傳送給家人點開即可自動帶入加入。
10. **OTA 無感熱更新（EAS Update）與版本資訊卡**：
    - 手機安裝一次 APK，日後前端介面更新**無需重新下載安裝 APK**，打開 App 自動在背景抓取最新介面。
    - 家庭分頁底部提供「應用程式版本資訊」卡片，清楚顯示版本號、Update ID、更新發布時間，並提供【🔄 檢查並載入最新版本】手動更新鈕。
11. **離線優先（Local-First）與極致效能**：
    - 無網路或賣場地下室仍可流暢記帳，連網後自動補推同步。
    - 採用當月快照與分批無感加載技術，累積數萬筆資料依然秒開。
12. **🤖 Supabase 永不休眠保活 ＋ LINE 群組每日收支日報**：
    - 透過 GitHub Actions 每天定時對 Supabase 進行外部 API 存取打卡，重設 7 天休眠計時器，徹底杜絕免費版資料庫被暫停的風險。
    - 每天 21:30 定時運算當日收支與月度累計，以 LINE 官方 Flex Message 原生卡片推播至家庭 LINE 群組。
13. **📱 成員連線裝置感知與設備管理（Phase 1）**：
    - **成員裝置感應**：家庭成員名冊卡片新增「📱 X 台裝置」徽章，直觀掌握每位家庭成員目前有多少台手機/電腦在線使用。
    - **連線設備清單**：點擊成員開啟設定彈窗，新增「📱 連線中的裝置清單」，清楚列出該成員綁定的所有設備名稱（iPhone、Pixel、Chrome 等）、平台圖示、App 版本與最後活動時間，並明確標記「本機裝置」。
    - **安全解除與舊設備踢除**：本人或帳本管理員可隨時一鍵解除遺失或除役的舊手機，雲端與本機即時雙向同步。
14. **🔐 Google 帳號一鍵綁定與身分電子鎖（Phase 2）**：
    - **可選安全升級（Opt-in Google Auth）**：於家庭設定專區提供一鍵綁定 Google 帳號，為個人家庭稱謂加裝電子鎖。
    - **身分防冒用與防奪取保護（Identity Lock）**：綁定後名冊顯示「🔒 已保護」徽章；未獲該 Google 授權之裝置全面禁止竄改稱謂或冒名認領。
    - **各帳本稱謂 100% 獨立保有**：Google 帳號僅作為全域通行證與身分鎖，各公帳稱謂（如公帳叫「智爸」、私帳叫「阿智」）完全各自獨立，絕不強制統一稱謂。
    - **換手機/重新安裝無縫認領（身分恢復）**：支援「以 Google 帳號認領 / 恢復舊身分」，換新設備時透過線上 Google 驗證或 6 位數認領碼，一秒找回專屬身分與管理權限。
    - **長輩小孩訪客模式零摩擦**：未綁定 Google 的成員維持訪客模式無感使用，日常記帳、分帳與公帳運作完全不受任何影響。
    - **零新增原生模組（100% EAS OTA 相容）**：採用純 Web/深層連結相容架構，雲端熱更新即刻生效，無需重新下載安裝 APK。

### 📦 v1.0.5

#### 1. 🚌 悠遊卡/儲值卡快速加值出資來源全面重構（通用動態支付方式 ＋ 信用卡/銀行子帳戶連動）
* **出資來源動態化（告別硬編碼打補丁）**：悠遊卡/儲值卡快速加值小工具全面重構，不再寫死固定選項，而是直接動態讀取家庭啟用的支付方式體系（現金、信用卡、銀行轉帳、悠遊付、街口支付、全支付、LINE Pay 等）。
* **支援悠遊付/電子支付多元管道加值記錄**：點選悠遊付或街口支付時，預設直接以「錢包餘額/直接扣款」轉入悠遊卡，亦可自選綁定之信用卡出資，精準對應台灣日常使用悠遊付 App 靠卡加值後之記帳需求！
* **銀行轉帳動態連動特定銀行帳戶**：點選「銀行轉帳」時，系統會自動展開該出資人的銀行帳戶清單（如玉山銀行、台新 Richart），亦可選「一般轉帳（不指定銀行）」，清楚追蹤哪家銀行出資。
* **出資人動態卡片過濾**：快速加值彈窗中，扣款出資來源自動跟隨「出資付款人」動態篩選其名下卡片，畫面清爽不再塞滿全家所有卡片；並提供「展開全家卡片 (N) ▾ / 僅顯示出資人卡片 ▴」切換按鈕，保留靈活代付彈性。
* **自動轉帳明細智慧標記**：加值確認提示與產生的內部轉帳明細，精準標記出資管道（如「悠遊付錢包」、「銀行轉帳·玉山銀行」、「信用卡·富邦J卡」），並納入各卡或帳戶核算，不重複計入家庭總支出。

#### 2. 📥 內部轉帳專屬「轉入目標卡片 / 受款成員」視覺卡片與店家/備註自由輸入解耦
* **轉入終點獨立專屬呈現**：查看或編輯內部轉帳紀錄時，若為儲值卡加值，直接於表單中獨立展開「📥 轉入目標卡片：🚌 卡片名稱 (持卡人·即時餘額) [入帳卡片]」，資訊起訖兩端完全對稱。
* **零用錢轉帳自動對應受款成員**：若為家庭成員間發放零用錢之內部轉帳，同步清楚標示「📥 轉入受款成員：👤 成員名稱 (零用錢錢包入帳) [受款入帳]」，資金流向一目了然。
* **擺脫對備註與店家文字依賴**：系統全面讀取底層結構化 `linked_transaction_id`，即使備註欄留白或被清空，畫面上轉入目標卡片永遠清晰可見，徹底杜絕疑慮。
* **店家與備註欄 100% 自由填寫**：加值產生的內部轉帳紀錄，店家預設為「悠遊卡加值」，使用者可隨時自由改填生活化地點（如「7-11 敦南門市」、「台北捷運市府站」）或清空，對帳與卡片關聯永遠不受影響。

#### 3. 🎯 悠遊卡自然月對帳嚴格卡片歸屬校正（消弭跨卡重複計入疑慮）
* **修復跨卡加值錯列問題**：徹底解決先前對帳邏輯中因店家名稱包含「悠遊卡加值」引發無條件通配的缺陷，不再導致全家所有悠遊卡都列出同一筆加值。
* **結構化帳戶 ID 嚴格排他**：加值紀錄優先以專屬帳戶 ID (`linked_transaction_id`) 或備註卡名精準比對，若明確指向其他卡片，一律 100% 嚴格排除。

## ☁️ 連接至真實 Supabase 雲端資料庫（選用）

本系統預設自帶**本地示範與離線快取模式**，即使不連接雲端亦可立即點擊操作體驗。若要啟用真正的雲端多人同步：

1. 前往 [Supabase 官網](https://supabase.com) 註冊並免費建立一個專案。
2. 在 Supabase 後台左側點擊 **SQL Editor**，將本專案目錄下的 `supabase_schema.sql` 內容複製貼上並執行（一鍵自動建立所有資料表、RLS 安全機制、RPC 儲存程序與預設分類）。
3. 前往專案 **Settings -> API** 複製 `Project URL` 與 `anon public key`。
4. 在本專案根目錄建立 `.env` 檔案（或直接修改 `src/lib/supabase.ts`）：
   ```env
   EXPO_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   EXPO_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_xxxxxxxxxxxxxxxxxxxxxxxx
   ```
5. 重新啟動 App 或重新整理網頁，頂部的狀態徽章將立即轉為 **🟢 雲端已同步**！

系統內建了全自動化的 **GitHub Actions 雲端守護排程**，每天台灣時間 **21:30 (UTC 13:30)** 自動喚醒執行，達成兩大核心效益：
1. **Supabase 永不休眠（Keep-Alive）**：向 Supabase 進行真實 API 存取打卡，重設 7 天休眠計時器，徹底杜絕免費版資料庫被暫停（Paused）的風險。
2. **LINE 原生高質感 Flex 卡片日報**：統計全家今日開銷、成員貢獻與本月進度，推播至家庭 LINE 共同群組（或個人），排版嚴格對齊、永不破版折行。

### 📋 快速串接 4 步驟指南

#### 步驟 1：建立免費 LINE 官方帳號並啟用 Messaging API
1. 前往 [LINE Developers Console](https://developers.line.biz/)，點擊「Create a LINE Official Account」建立官方帳號（名稱可取為「甜心記帳本小幫手」）。
2. 在 LINE 官方帳號管理後台點選 **設定 ➜ Messaging API ➜ 啟用 Messaging API**，選擇您的 Provider 並確認啟用。
3. 回到 LINE Developers 控制台進入該頻道 ➜ **Messaging API** 頁籤最下方 ➜ 點擊 **Issue** 複製 **Channel Access Token**。

#### 步驟 2：取得家庭群組 Group ID（30 秒免註冊工具）
1. 用電腦打開免註冊測試工具 [https://webhook.site](https://webhook.site)，點擊頂部 **Copy** 複製專屬網址。
2. 在 LINE Developers 的 **Messaging API** 頁籤中：
   * 找到 **Webhook URL** ➜ 貼上該網址並儲存。
   * 將 **Use webhook** 開關切換為**開啟（綠色）**。
3. 打開手機 LINE，將「甜心記帳本小幫手」邀請加入全家人的 **LINE 家庭群組**（若已在群組，在群組隨便發一句話如 `123`）。
4. 查看 Webhook.site 網頁，在接收到的內容中找到 `"groupId": "Cxxxxxxxx..."`，複製該 **`C` 開頭代碼**。

#### 步驟 3：設定 GitHub 倉庫 Secrets
前往您的 GitHub 專案：**Settings ➜ Secrets and variables ➜ Actions ➜ New repository secret**，填入以下密鑰：

| Secret 名稱 | 說明與填寫內容 | 必要性 |
| :--- | :--- | :--- |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase 後台 **Project Settings ➜ API** 複製的 `service_role` (secret) 金鑰 | **強烈建議**（穿透 RLS 安全機制讀取帳本明細） |
| `LINE_CHANNEL_ACCESS_TOKEN` | 步驟 1 取得的 LINE Channel Access Token | 啟用 LINE 推播必填 |
| `LINE_TARGET_ID` | 步驟 2 取得的家庭群組 `Group ID`（`C...`）或個人 `User ID`（`U...`） | 啟用 LINE 推播必填 |
| `LEDGER_ID` | （選填）指定帳本 UUID。若不填系統會自動智慧鎖定最近活躍的單一主帳本 | 選填 |

#### 步驟 4：測試與驗證
* **GitHub 網頁手動觸發**：前往 GitHub 專案的 **Actions ➜ Supabase Keep-Alive & Daily Report ➜ Run workflow**，20 秒內 LINE 群組即可收到卡片！
* **本地終端機測試**：在本地 `.env` 填入上述變數後，執行：
  ```bash
  npm run report:daily
  ```

## 🚀 常用指令與運維操作

### 1. 本地開發與除錯
```bash
npx expo start        # 啟動開發伺服器
npx expo start --web  # 直接開啟網頁版除錯
npx tsc --noEmit      # 執行 TypeScript 靜態型別檢查
```

### 2. 部署電腦網頁版（GitHub Pages）
若修改了前端程式碼，發布至網頁版只需一行：
```bash
npm run deploy:web
```
發布後電腦重新整理頁面（[https://mattyu99.github.io/family-ledger/](https://mattyu99.github.io/family-ledger/)）即可體驗最新版。

### 3. 編譯 Android 原生 APK 安裝檔（EAS Build）
使用 Expo 官方免費雲端伺服器打包 APK（免裝本機 Android Studio）：
```bash
# 第一次使用前請先登入 Expo 帳號
npx eas-cli@latest login

# 啟動雲端打包 APK (產出直接可安裝的 .apk 檔)
npm run build:android
```
編譯完成後，終端機會直接顯示 **下載連結** 與 **QR Code**，手機掃碼即可下載安裝。

### 4. 推播手機 App 熱更新（EAS Update / OTA）
手機安裝過熱更新正式版 APK 後，未來修改介面**不需要重新打包 APK**，直接推播：
```bash
npm run update:android -- --message "版本更新備註"
```
家人手機下次打開 App 時就會自動無感套用最新畫面。

## 🏷️ 版本號更新規範（語意化版本 SemVer）

本系統遵循 `主版本 (Major) . 次版本 (Minor) . 修訂號 (Patch)` 格式：

* **修訂號 (Patch，例如 `1.0.5` ➜ `1.0.6`)**：用於修正 Bug、介面微調、效能優化與備份功能擴展。
* **次版本 (Minor，例如 `1.0.6` ➜ `1.1.0`)**：新增全新大功能模組（如自訂預算警示），原有功能相容。
* **主版本 (Major，例如 `1.x.x` ➜ `2.0.0`)**：重大架構改版或底層資料表重構。

### 如何前進版本號？
只要打開 **`app.json`** 與 **`package.json`**，將 `"version"` 修改為新版本號（如 `"1.0.6"`），App 介面卡片將**自動連動顯示**新版本號！

## 🛡️ 品質規範與最佳實踐

1. **溫馨家庭公帳共同分擔原則**：全系統完全以家庭公帳共同分擔支出為核心，無借貸討債負擔，不需繁複的內部平攤計算。
2. **極致防爆字排版**：所有文字元素皆具備 `allowFontScaling={false}` 與 `maxFontSizeMultiplier={1.08}`，確保跨廠牌手機排版整齊統一。
3. **管理員安全 PIN 碼**：預設 PIN 碼為 **`8888`**。建立帳本後，建議管理員前往【成員】頁面修改為專屬 PIN 碼，並妥善與另一位主要管理者共享。
4. **定期備份習慣**：善用內建的 7/14/30 天自動提醒，一鍵存檔備份至個人 Google 雲端硬碟或 iCloud，守護家庭核心資產歷史。
