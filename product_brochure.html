🎯 解決現代家庭的四大記帳痛點

常見家庭痛點 傳統記帳軟體的問題 💖 甜心記帳本的優雅解法
痛點 1：各記各的、資料分散 夫妻各自用不同 App，每到月底根本不知道全家總共花去哪裡。 多人即時雙向連線：一人一機綁定家庭稱謂，一人記帳全家秒同步，隨時掌握全家財務全貌。
痛點 2：生硬 AA 算帳破壞感情 傳統拆帳軟體充滿借還款與討債介面，家庭記帳變得斤斤計較。 家庭公帳共同分擔：以共同預算與公帳平衡為核心，免除借貸壓力；支援雙向零用錢收支自動平衡。
痛點 3：記帳與生活待辦脫節 超市採買清單在備忘錄，買完又要打開記帳手動補記，常常忘記漏記。 生活手帳 ＋ 辦妥打勾 ＋ 連動記帳：採買清單隨手打勾，一秒連動轉為公帳支出，自動保留採買回報氣泡。
痛點 4：信用卡、悠遊卡對帳一團亂 悠遊卡儲值到底算支出還是轉帳？信用卡帳單週期與月曆收支對不上。 雙軌智慧對帳看板：信用卡依結帳日切期、悠遊卡依自然月對帳，支援悠遊付/街口加值與子帳戶連動。

📱 十四大產品核心模組全覽

1. 📝 智慧記帳與生活手帳（流水帳清單）

  • 收支與內部轉帳：極速記帳，智慧記憶常用店家與分類圖示。
  • 發生時間 (時:分) 微調：自訂時分與「設為現在」按鈕，編輯後自動時序歸位，不再早下記昨晚順序錯亂。
  • 手帳手記模式 ($0)：隨手記錄靈感、清單或生活隨筆，嚴格排除於財務收支統計。
  • 店家即時搜尋與熱門膠囊：支援店家快搜，點擊橫向標籤膠囊（如 [好市多]）一秒快篩並動態加總。

2. 📋 生活備忘待辦與打勾辦妥連動

  • 五大分頁待辦總覽：集中「全部待辦」、「🚨 逾期」、「🔔 今日」、「🕒 未來」與「✓ 已完成」。
  • 辦妥確認彈窗：打勾時自選辦妥人、填寫「辦妥補充說明/回報」與快捷標籤。
  • 連動公帳支出：採買完畢一鍵連動轉記支出，卡片自動展示連動支出膠囊與專屬綠色留言氣泡。
  • 草稿防退回保護：連動記帳若按取消，自動退回辦妥彈窗，原先填寫之備註 100% 完好留存。

3. 🎯 雙視角預算控管與即時 WebSocket 雲端同步

  • 家庭公帳月預算與警戒門檻：配置公帳月度總預算、80% 警戒超支門檻與分類預算，動態進度條即時警示。
  • 個人額度自主掌控：每位成員可於自己手機上設定個人開銷額度，互不干涉，落實個人自主與隱私。
  • 管理員權限保護：公帳總預算僅管理員可設定修改，一般成員提供唯讀瀏覽模式與提示徽章。
  • WebSocket 跨裝置秒級推播：一人調整額度，全家全體裝置秒級連動更新。

4. 💎 四大資產、信用卡待繳與財務淨值看板

  • 四大資產型態全要素整合：統整銀行帳戶、現金皮夾、儲值票證與信用卡待繳負債，動態計算淨值。
  • 個人淨值 vs. 家庭淨值智慧切換：預設呈現本機成員個人的資產淨值，切換全部成員統整全家財務淨值。
  • 小眼睛隱私遮罩：首頁資產金額預設啟用星號遮罩 (NT$ ••••••)，外出檢視無拘無束。
  • 展開明細清單：一鍵展開完整帳戶清單，各卡即時餘額、持卡人與待繳金額清晰可見。

5. 📊 多維度財務統計與視覺化報表

  • 四大核心財務 KPI：總支出（含出資轉出）、總收入、當月結餘、公帳淨結算即時計算。
  • 動態彩色排行榜：飲食、居家、育兒各類別佔比進度條與成員支出貢獻分佈一目了然。
  • 歷年月份任意穿透與走勢：提供年份切換、走勢圖表與 12 個月網格任意挑選彈窗，數年明細秒查秒看。

6. 💳 週期扣款、水電瓦斯與信用卡分期

  • 固定帳單排程：相容台灣台電、自來水、瓦斯單雙月繳，到期提醒與「一鍵確認入帳」核對。
  • 分期付款進度追蹤：支援 3~36 期自訂期數，每期標註 (第 X/Y 期)，繳滿全額自動除役。
  • 電子帳單雲端保管庫：每張卡獨立上傳 PDF 或圖片帳單，出門在外帳單明細隨身查。

7. 🚌 悠遊卡通用動態加值與自然月對帳

  • 出資管道全面動態化：加值時連動家庭啟用支付方式（現金、信用卡、銀行轉帳、悠遊付、街口等）。
  • 悠遊付/電子支付多元出資：支援以悠遊付或街口餘額/信用卡出資，精準對應悠遊付 App 靠卡加值之記帳需求。
  • 內部轉帳終點可視化：加值明細清楚展示「📥 轉入目標卡片：🚌 卡片名稱 (持卡人·即時餘額)」。
  • 自然月嚴格排他對帳：依專屬帳戶 ID 判定，徹底拔除盲目通配，當月加值存入統計精確無誤。

8. 👨‍👩‍👧 家庭協作、身分管理與雙向零用錢

  • 一人一機身分識別：手機清楚標示 📱 我 (本機)，記帳自動帶入本人，亦可代家人記帳。
  • 雙向零用錢機制：家長記出資支出，孩子記零用錢收入，家庭公帳總額與個人結餘雙向平衡。
  • 個人卡片自主管理：每位成員可自主新增、修改、刪除自身卡片與帳戶，管理員享全家代管特權。
  • 代記帳人編輯權限：幫家人記帳後依然享有編輯權限；非出資者瀏覽自動開啟「🔒 唯讀模式」防呆。

9. 🔐 Face ID / 指紋辨識隱私防護鎖與企業級資安

  • 原生生物辨識身分保護：深度整合 expo-local-authentication，支援 iOS Face ID / Touch ID 與 Android 指紋辨識。
  • 資產小眼睛輕觸解鎖：資產看板與帳戶金額預設星號遮罩，輕觸指紋或 Face ID 秒速解除遮罩。
  • App 啟動與喚醒防護鎖：冷啟動或自背景返回 App 時強制驗證生物辨識或輸入 4 碼 PIN 碼解鎖。
  • 4 位數管理員 PIN 碼：預設 8888，敏感設定強制驗證；最後一位管理員防呆保護。
  • Google 身分電子鎖：一鍵綁定 Google 帳號，名冊顯示「🔒 已保護」，換手機秒認領身分。
  • 連線設備感知管理：名冊展示在線裝置數量徽章，支援查看連線清單、型號並一鍵踢除舊設備。

10. 🔔 生活記事與信用卡帳單智慧推播雙軌系統

  • 生活記事到期本機推播：已設定提醒日期之記事於當天上午 09:00 本機推送通知 (expo-notifications)。
  • 記事辦妥排程即時註銷：記事在 App 內被勾選辦妥完成時，自動即時取消本機通知排程，精準不打擾。
  • 信用卡出帳與繳款提醒：出帳日隔天 09:30 與繳款日前 3 天 09:30 智慧提醒，精準提示待繳金額。
  • LINE 收支日報雙向連動：每日 21:30 收支日報新增「📌 生活記事與待辦備忘提醒」卡片與帳單提醒標籤。

11. ⚡ 手機桌面 Quick Actions 快捷直達與 Deep Linking

  • 桌面長按快捷直達：手機桌面長按 App 圖示，彈出「記支出」、「記收入」、「掃描發票」、「隨手記事」4 大捷徑一秒直達。
  • 相機掃描直通：選擇「掃描發票 / 收據」捷徑自動直達相機掃描器，秒速辨識明細。
  • 自訂 URL Scheme 外部連動：支援 familyledger://quick-action 協定，可串接 iOS 捷徑、Siri 語音。
  • 隱私鎖安全佇列：若啟用生物辨識防護，長按捷徑進入時先通過生物辨識驗證，隨後自動流暢執行。

12. 📷 統一發票雙 QR Code 智慧掃描、Gemini 雲端 OCR 與自動對獎

  • 發票雙條碼鏡頭即時並排掃描：左右雙對焦輔助框，鏡頭對準電子發票雙碼，秒速自動帶入號碼、金額、消費日、店家與長明細。
  • Google Gemini 多模態雲端辨識：Supabase Edge Function (gemini-ocr) 封存 API Key，傳統收據拍照高精解析，前端無縫備援。
  • 大賣場長明細無縫合體：長商品發票自動連續捕捉左右碼溢位明細並智慧融合成單筆記錄，附帶 2 秒容錯機制。
  • 雲端發票相簿截圖解析：支援從手機相簿直接選取截圖自動解析發票雙條碼，解決無實體紙本痛點。
  • 百大連鎖統編自動辨識：內建全聯、好市多、家樂福、四大超商等百大統編庫，掃碼帶入店家與分類。
  • 開獎比對與對獎中心一鍵兌領：卡片即時亮起中獎徽章，對獎中心支援「一鍵兌領入帳」自動產生收入平帳。

13. 🛡️ 企業級資安、PIN 碼防護與全要素備份

  • 6 大全要素封存指標網格：完整備份交易、成員、分類、卡片、週期、付款方式，支援安全合併還原。
  • 家庭門禁安全鎖：通道開關上鎖時阻斷持邀請碼新訪客加入並隱藏名冊，防範邀請碼外流。
  • 資料自主權 100% 歸還家庭：隨時支援全要素一鍵匯出 JSON 備份檔與 CSV 報表，不受平台綁架。

14. ⚡ 離線優先技術、全域安全邊界與 LINE 每日家庭收支報表

  • 離線優先 (Local-First)：賣場地下室無網順暢記帳，離線寫入佇列在連網後背景自動重試同步。
  • 防禦型原生模組載入：原生模組安全探測與優雅降級，未編譯模組環境自動切換 PIN 碼防護，杜絕 OTA 黑屏。
  • 全域根層安全邊界 (Root Error Boundary)：應用程式頂層掛載保護層，攔截例外並提供一鍵恢復按鈕。
  • EAS Update 無感熱更新：功能升級自動背景下載套用，免繁瑣手動更新安裝。
  • LINE 群組 Flex 報表：每日 21:30 定時運算並推播圖文卡片至家庭 LINE 群組，兼具 Supabase 保活打卡。

🏡 四大家庭日常實用情境演繹

情境 A：太太超市採買（生活待辦 ➔ 綠色回報 ➔ 採買連動支出）
  1. 先生出門前在記帳本留下一則生活待辦：［採買］鮮奶兩大瓶、雞蛋一盒、牛排。
  2. 太太在全聯買好後點擊勾勾，彈出確認視窗，填寫回報：「已買好特價鮮奶，牛排改去好市多買」。
  3. 點選「💳 連動記一筆支出」，輸入金額 $420，選擇付款方式為全聯福利卡。
  4. 儲存後，先生手機即刻收到推播泡泡：✓ 太太 辦妥了一項待辦！，卡片附帶綠色留言氣泡與 💳 支出 NT$ 420 連動膠囊。
情境 B：月初家長發放孩子零用錢
  1. 爸爸點選「新增 ➔ 內部轉帳」，選擇「發放零用錢」。
  2. 出資人選爸爸（從薪轉戶扣除 $1,000），受款成員選「豆豆」。
  3. 系統自動入帳：爸爸帳下記錄 $1,000 出資；豆豆的零用錢錢包增加 $1,000 結餘；家庭總結餘維持平衡。
情境 C：通勤捷運悠遊卡手機感應加值
  1. 媽媽在捷運站以手機悠遊付感應為「富邦J悠遊卡」加值 $500。
  2. 打開快速加值小工具：卡片選富邦J悠遊卡、出資方式選「悠遊付錢包」、金額 $500。
  3. 系統自動建立內部轉帳明細，清楚展示「📥 轉入目標卡片：富邦J悠遊卡」，店家改填「台北捷運市府站」。
  4. 月末查看悠遊卡對帳，$500 準確列於當月加值存入；其他家人的卡片清清爽爽，絕不跨卡錯列！
情境 D：月末大螢幕電腦網頁精確核對信用卡帳單
  1. 收到信用卡帳單，電腦瀏覽器開啟網頁版。
  2. 進入「信用卡帳單精確對帳」，系統自動對齊結帳日週期（例如 10/16 ~ 11/15）。
  3. 對照銀行帳單逐筆打勾確認核對；點擊「🎁 登記回饋折抵」一鍵抵扣，當期應繳金額自動算到分毫不差！
