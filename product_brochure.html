🎯 解決現代家庭的四大記帳痛點

常見家庭痛點 傳統記帳軟體的問題 💖 甜心記帳本的優雅解法
痛點 1：各記各的、資料分散 夫妻各自用不同 App，每到月底根本不知道全家總共花去哪裡。 多人即時雙向連線：一人一機綁定家庭稱謂，一人記帳全家秒同步，隨時掌握全家財務全貌。
痛點 2：生硬 AA 算帳破壞感情 傳統拆帳軟體充滿借還款與討債介面，家庭記帳變得斤斤計較。 家庭公帳共同分擔：以共同預算與公帳平衡為核心，免除借貸壓力；支援雙向零用錢收支自動平衡。
痛點 3：記帳與生活待辦脫節 超市採買清單在備忘錄，買完又要打開記帳手動補記，常常忘記漏記。 生活手帳 ＋ 辦妥打勾 ＋ 連動記帳：採買清單隨手打勾，一秒連動轉為公帳支出，自動保留採買回報氣泡。
痛點 4：信用卡、悠遊卡對帳一團亂 悠遊卡儲值到底算支出還是轉帳？信用卡帳單週期與月曆收支對不上。 雙軌智慧對帳看板：信用卡依結帳日切期、悠遊卡依自然月對帳，支援悠遊付/街口加值與子帳戶連動。

📱 十四大產品核心模組全覽

1. 📝 智慧記帳與生活手帳（流水帳清單）

  • 收支與內部轉帳：極速記帳，智慧記憶常用店家與分類圖示。
  • 發生時間 (時:分) 微調：自訂時分與「設為現在」按鈕，編輯後自動時序歸位，不再早下記昨晚順序錯亂。
  • 手帳手記模式 ($0)：隨手記錄靈感、清單或生活隨筆，嚴格排除於財務收支統計。
  • 店家即時搜尋與熱門膠囊：支援店家快搜，點擊橫向標籤膠囊（如 [好市多]）一秒快篩並動態加總。

2. 📋 生活手帳待辦總覽與辦妥連動

  • 待辦專屬總覽視角：隨時切換「進行中待辦」與「已辦妥歸檔」，支援「全部 / 我的」成員篩選。
  • 辦妥確認彈窗 (MemoCompletionModal)：點擊待辦打勾彈出確認彈窗，支援填寫補充說明與點選情境標籤。
  • 綠色留言氣泡：辦妥後卡片下方生成貼心回報氣泡（如「已送達家中、發票放餐桌」），全家清晰可見。
  • 一鍵連動公帳支出：採買項目打勾時可勾選「連動記一筆公帳」，自動帶入品項與金額，記帳生活二合一。

3. 🎁 雙向零用錢發放模型

  • 全台首創零用錢架構：徹底解決傳統記帳軟體「出資算支出還是轉帳」的矛盾。
  • 自動雙向平衡：爸媽記錄一筆教育支出，孩子名下錢包自動增加正向零用錢可用額度，公帳收支完美平衡。

4. 🧾 台灣電子發票雙碼辨識與自動對獎

  • 雙 QR Code 秒級掃描：同時辨識左右雙碼，自動剖析明細、期別與品項。
  • 全帳本防重複記帳：家人若已記過相同發票，系統即時亮紅警示，徹底防杜重複。
  • 官方獎號全自動同步：單月 25 日背景連線財政部抓取開獎號碼，歷史發票毫秒級自動對獎。
  • 一鍵兌領入帳：中獎發票可一鍵轉為中獎收入並匯入指定錢包。

5. 🗓️ 固定週期帳單管理與滾動 7 天時間軸

  • 週期規則設定：水電瓦斯、房租通訊、串流訂閱（每月、雙月、季繳、半年、年繳）。
  • 滾動未來 7 天時間軸：依「逾期 ➔ 今日 ➔ 明日 ➔ 未來 7 天」平鋪排序，告別無謂虛驚紅點。
  • 一鍵確認入帳：收到繳費單點擊一鍵入帳，自動轉為公帳支出並推進至下一期。

6. 💳 信用卡分期付款攤提追蹤

  • 3 ~ 36 期彈性設定：購買高額家電或手機時自由選擇攤提期數。
  • 視覺進度條：清晰展示已繳期數、剩餘期數與已攤提金額。

7. 💎 四大資產看板與即時財務淨值

  • 現金、銀行、票證、信用卡負債：首頁頂部即時運算全家真實財務淨值。
  • 小眼睛星號遮罩：保護隱私，輕觸 Face ID / 指紋一秒解鎖顯示數字。
  • 雙重視角秒切：自由切換「個人淨值」與「家庭淨值」。

8. 📊 雙軌智慧對帳系統

  • 信用卡週期對帳：精準對齊每月結帳日（如 15 號結帳即切為 9/16 ~ 10/15），逐筆打勾核對。
  • 悠遊卡自然月排他對帳：各卡獨立餘額、動態出資人加值與快捷累加鍵。

9. 🎯 雙視角預算控制

  • 家庭公帳總預算：管理員設定全家總額度，80% 警戒超支提醒與超支警報。
  • 成員個人額度自主配置：每人可自訂個人開銷額度，WebSocket 秒級連動同步。

10. 📈 多維財務統計與報表

  • 四大財務 KPI：總支出、總收入、當月結餘、日均消費。
  • 多維圖表：類別支出排行佔比條狀圖、成員貢獻比例圓餅圖、歷史跨月趨勢對比。

11. 📱 Android 桌面 3D 黏土小工具

  • 2x2 快捷記帳小工具：記支出、掃發票、記收入、隨手記 4 大按鈕直通記帳。
  • 4x2 生活手帳待辦小工具：常駐 4 則最急待辦，點選直達辦妥確認，🔄 手動刷新與背景秒級重繪。
  • 桌面長按 Quick Actions：長按 App 圖示喚出系統級捷徑選單。

12. 🛡️ 零信任身分與管理員生物辨識提權

  • 訪客模式保護：未審核裝置僅唯讀瀏覽，禁止偽冒修改。
  • 生物辨識原生提權：管理員修改設定無需背誦 PIN 碼，10 分鐘自動降級。
  • Google 帳號身分鎖：換機或重灌時登入 Google 瞬間自動認領歸戶。

13. 💾 6 大全要素封存備份與安全合併還原

  • 全要素 6 大領域封存：明細、名冊、分類、卡片、週期規則、常用付款方式。
  • 安全智慧合併：匯入歷史資料自動依 ID 去重，永不覆蓋遺漏。

14. 🤖 LINE 群組每日 Flex 圖文收支日報

  • GitHub Actions 定時推播：每晚自動產出精美 Flex 卡片推播至全家群組。
  • Supabase 雲端保活：每日排程呼叫兼具雲端免費資料庫自動活躍防休眠。

👨‍👩‍👧‍👦 典型家庭使用情境示範

情境 A：超商超市採買 ➔ 一鍵打勾連動記帳
  1. 出門前，媽媽在 App 生活備忘新增待辦「全聯買鮮乳與生鮮雞蛋」。
  2. 爸爸下班到全聯採購完畢，手機打開 App 點擊待辦左側打勾。
  3. 彈出辦妥確認彈窗，爸爸選擇由自己辦妥，勾選「連動記一筆公帳」，輸入金額 $210。
  4. 儲存後系統自動完成：待辦標記辦妥、留下綠色回報氣泡，同時自動建立一筆公帳支出！
情境 B：發放孩子段考獎學金 ➔ 雙向零用錢平衡
  1. 段考結束，爸爸點擊記帳彈窗「🎁 撥零用錢」。
  2. 選擇出資人「智爸」，受款人「洋洋」，金額 $1,000，備註「段考進步獎學金」。
  3. 儲存後：智爸記一筆教育支出，洋洋名下錢包可用額度自動增加 $1,000，全家公帳完美平衡。
情境 C：信用卡帳單出帳 ➔ 精確對帳與折抵
  1. 收到銀行電子帳單，App 提示即將到期。
  2. 進入「信用卡帳單精確對帳」，系統自動對齊結帳日週期（例如 10/16 ~ 11/15）。
  3. 對照銀行帳單逐筆打勾確認核對；點擊「🎁 登記回饋折抵」一鍵抵扣，當期應繳金額自動算到分毫不差！
